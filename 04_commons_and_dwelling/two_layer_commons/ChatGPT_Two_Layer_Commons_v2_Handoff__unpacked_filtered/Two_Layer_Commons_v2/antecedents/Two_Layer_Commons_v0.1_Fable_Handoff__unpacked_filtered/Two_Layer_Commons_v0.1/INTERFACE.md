# Interfaces

## Body and choice

Body to choice, through an immutable `Sensation` supplied by the scheduler:

- `short` reports whether total available provision is below the fixture threshold.
- `settled` reports the current physiological outcome.
- `independent_available` reports a current opportunity, derived from the shared ground and encounter.
- `needs_repair` reports an active relational outcome.

Choice additionally gets the current tick, an equally scheduled story invitation,
and the relationship status (`none`, `observed`, `approached`, `asked`,
`restored`). Its explicit evidence selection yields a source label and
that source's reading. A successful explicit story request yields the
answer-free projection.

Choice to body, through the scheduler:

- A clench changes the next tick's physical gate input. It never prevents
  a body invocation or sets a body value directly.
- An approach or request is sent to the outside restoration process. An
  exact independently signed receipt from the test owner supplies the
  physical release input for the next tick.

An evidence action, history request or constitutional proposal does not
write body state. Choice receives no body object, raw terrain, reserves,
fault tape, test truth, kernel object, or signing key.

## World, kernel and observer

The world supplies contact, terrain-derived friction, abrasion,
destination-free pulse, noise, and the three physiological fault flags.
The body returns forwarded and blocked provision to the world. The world
boundedly stores spill for the next encounter. Its own fault flag can
interrupt ground work. Alpha's final ground can seed Beta's outside
environment through the ground arm. The story is copied only in story
arms, and terminal circulating provision is matched across all arms.

A proposal request gives the host a fixed test transcript. The canonical
kernel constructs the exact mutation envelope. The host passes its payload
to the external fixture and sends the signature or empty refusal back to
the kernel. The witness checks the installed head. An independent outside
repair receipt binds the member, incident, trigger, arm, tick and burden
write. The member receives the physical outcome, with no ability to grant it.

Body snapshots, tape truth, source IDs, observer scores and kernel snapshots
go to the trace only. Python modules and immutable inputs create an explicit
structural interface for the experiment. Hostile same-process code is
outside this fixture's threat model.

Each tick is the atomic write unit for physiological effects. The unsigned
ledger reports before and after committed values. Internal arithmetic
within that write, including an expenditure canceled by same-tick intake,
has no independent observable state. LAYERS.md lists the capacity of each
resulting store.
