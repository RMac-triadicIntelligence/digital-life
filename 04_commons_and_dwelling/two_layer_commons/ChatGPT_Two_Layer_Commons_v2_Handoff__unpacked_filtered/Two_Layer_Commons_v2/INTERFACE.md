# Layer interfaces

The scheduler owns the objects and calls automatic function at every tick.
A member cannot call it, skip it, or select its rates. The decision module
receives immutable or copied data. Each state write and decision has an
actor, layer and location in the trace.

## Founder to reader

The founder process exits before the reader process starts. The founder's
temporary state directory is deleted. The reader process starts in a
fresh working directory with a copy of one JSON handoff and its independent
reader opportunity seed. The only schema fields are three channel cells,
three silt cells and a bounded literal story (or null). Alpha's raw
trajectory stays in a different working directory. Shape, permissions,
biography, previously interpreted meaning, and internal fields are
absent from the handoff. The verifier tries extra fields and malformed
values. This is an experimental data-flow boundary in trusted local code.

The observer can read all stores, the current opportunity and hidden
truth. Its traces and scores never feed back to members. Provision's
identifiers allow exact conservation checks and distinguish circulation
events from distinct units. IDs are tick/local sequence labels and are
recreated independently in each counterfactual.
